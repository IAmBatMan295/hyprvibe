# HyprVibe

Hyprland desktop configuration and installer for CachyOS.

## Install

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/IAmBatMan295/hyprvibe/main/bin/install.sh)"
```

Manual clone:

```bash
git clone https://github.com/IAmBatMan295/hyprvibe.git ~/hyprvibe && bash ~/hyprvibe/bin/install.sh
```

## Diagnostics

```bash
~/hyprvibe/bin/hyprvibe-doctor
```
